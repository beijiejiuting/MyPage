    # Web-Management

    • 项目成果:该教务管理系统,能够在局域网内访问,用户登录成功后可以操作学生信息与学院信息 ①登录校验:使用JWT令牌技术和Interceptor拦截器实现,用户必须登录成功才能访问信息 ②学院管理:对学院信息增删查改,删除学院时会同时删除该学员所有学生 ③学生管理:对学生信息增删查改,可以按条件筛选(姓名,性别,入学时间) ④文件上传:实现了一个工具类,使用阿里云OSS实现文件上传和访问
    • 开发技术: 该项目使用SpringBoot框架 ①按照三层架构开发,提高内聚,降低耦合,提高可维护性与可拓展性 ②使用Controller对请求做不同的处理和跳转 ③运用Spring IOC依赖注入实现对象的动态注入 ④使用Mybatis简化数据库连接,提高开发效率和灵活性 ⑤使用SpringAOP实现操作日志的记录

@WebFilter("url")
public class LoginCheckFilter implements Filter{
     @Override
     public void doFilter(ServletRequest request,
                          ServletResponse response, FilterChain chain) {
         //操作
         if(放行)chain.doFilter(request,response);
         else return;
     }
}
//拦截器
//先在配置类里注册
@Autowired
    private LoginCheckInterceptor loginCheckInterceptor;
    @Override
    public void addInterceptors(InterceptorRegistry registry) {
        registry.addInterceptor(loginCheckInterceptor)//定义路径
            .addPathPatterns("/**")
            .excludePathPatterns("/login");
    }
@Component
public class LoginCheckInterceptor implements HandlerInterceptor {
    @Override
    public boolean preHandle(HttpServletRequest request,
                             HttpServletResponse response, Object handler) {
        //操作
         if(放行)return true;
         else return false;
    }
