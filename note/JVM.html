    # 分代收集

    根据对象存活周期的不同会将内存划分为几块，把 Java 堆分为新生代和老年代

    # Eden区

    新生代,空间不够时,JVM发起一次Minor GC,存活的进入Survivor区

    # Survivor区

    在Survivor区每次经历Minor GC,对象年龄+1,15岁时到Old区

    (动态对象年龄:如果 Survivor 空间中某个年龄段的对象总大小超过了 Survivor 空间的一半，那么该年龄段及以上年龄段的所有对象都会在下一次垃圾回收时被晋升到老年代)

    分成两个区From/To

    每次Minor GC,把Eden存活和From区的复制到To

    下次Minor GC,From和To交换职责

    好处是不用标记清除,一个区为空,另一个也没有碎片

    # Old区

    这里使用标记整理

    大对象直接进入老年代

    占据堆区2/3,只有Major GC才清理,每次需要STW

    # new对象过程

    JVM 首先会检查 new 指令的参数是否在常量池，然后检查这个类是否已被加载。如果没有，就先执行相应的类加载过程。

    如果已经加载，JVM 会为新生对象分配内存，将分配到的内存空间初始化为零，设置对象头，对象头里包含了对象是标记字（哈希码、GC 分代年龄、锁等信息），类型指针，数组长度（如果是数组）等信息。 最后，JVM 会执行构造方法（init），将成员变量赋值。

    在堆内存分配对象时，主要使用两种策略：指针碰撞和空闲列表。

    # new对象内存分配发生抢占
    • 采用 CAS 分配重试的方式来保证更新操作的原子性
    • 每个线程在 Java 堆中预先分配一小块内存，也就是本地线程分配缓冲（Thread Local AllocationBuffer，TLAB），要分配内存的线程，先在本地缓冲区中分配，只有本地缓冲区用完了，分配新的缓存区时才需要同步锁定。

    # 逃逸分析

    对象不一定分配在堆中

    方法逃逸：可能作为参数传递到外部

    线程逃逸：可能被外部线程访问到

    好处

    • 确定不会线程逃逸：栈上分配，同步消除
    • 确定不会方法逃逸：标量替换（不创建对象，使用若干个成员变量

    # 方法区

    # 对象的四种引用

    • 强引用是最传统的引用的定义，是指在程序代码之中普遍存在的引用赋值，无论任何情况下，只要强引用关系还存在，垃圾收集器就永远不会回收掉被引用的对象。

    • 软引用是用来描述一些还有用，但非必须的对象。只被软引用关联着的对象，在系统将要发生内存溢出异常前，会把这些对象列进回收范围之中进行第二次回收，如果这次回收还没有足够的内存， 才会抛出内存溢出异常。

    • 弱引用一定被回收

    • 虚引用一定被回收，唯一目的只是为了能在这个对象被收集器回收时收到一个系统通知。

    # 类加载过程

    加载

    获取类的二进制字节流、把字节流代表的静态存储结构转化为方法区的运行时数据结构、生产Class对

    验证（校验二进制字节流）

    准备（分配内存，初始化为默认值）

    解析（虚拟机将常量池内的符号引用替换为直接引用）

    初始化 （类变量将被赋值为代码期望赋的值）

    验证、准备、解析三个部分统称为连接（Linking）。

    # 类加载器

    负责加载类文件，将类文件加载到内存中，生成 Class 对象。

    启动类加载器Bootstrap ClassLoader）负责加载 JVM 的核心类库 扩展类加载器(Extension ClassLoader)：负责加载JAVA_HOME/jre/lib/ext目录下，或者由系统属性java.ext.dirs指定位置的类库。 应用程序类加载器（Application ClassLoader)：负责加载系统类路径（classpath）上的类库，通常是我们在开发 Java 应用程序时的主要类加载器。 我们编写的任何类都是由应用程序类加载器加载的，除非显式使用自定义类加载器。 用户自定义类加载器(User-Defined ClassLoader):我们可以通过继java.lang.ClassLoader类来创建自己的类加载器。

    # 双亲委派模型

    当一个类加载器收到类加载请求时，它首先不会自己去尝试加载这个类，而是把请求委派给父类加载器去完成，依次递归，直到最顶层的类加载器，如果父类加载器无法完成加载请求，子类加载器才会尝试自己去加载。

    # 目的

    保证 Java 核心类库的类型安全

    避免类的重复加载
